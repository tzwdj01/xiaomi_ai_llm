## 两台机器的区别

| | MDZ-25-DA / S12A | S12 |
|---|---|---|
| 上次确认的系统 | 1.76.54，内核 4.9.61 | 1.74.18，内核 3.14.29 |
| 文件系统 | system1 SquashFS，`/dev/mtdblock5` | system1 UBIFS，实际 UBI 到 MTD 的映射须重新核验 |
| 连续追问 | 该机此前验证了音箱端方案 | 本机实验依赖 Mac 的 Whisper 转写服务；Mac 必须开机、同网且 IP 正确 |

`uname -m` 是内核架构，不能单独证明原生进程 ABI。S12 的 `/data` 很小，原分区备份与坏块恢复尚未完整验证；不要跨机型套写镜像或分区。上次 S12 `/data` 曾出现内容丢失，原因未明。

## S12 语音与进程实验

`s12-device/last-local-s12-client.sh`来自本机最后保存的 S12 定制客户端快照，包含隔离进程和静默问答修复；**并非从音箱实时导出**。2026-11-17 两台设备当时无法连接，不能确认此源码仍与设备完全相同。源码默认测试地址已改为回环地址，私有配置不包含在仓库。

上次记录：针对首轮较长提问，原来的 3 秒等待可能在最终识别返回前结束；本机候选将等待设为 15 秒，并在完整识别、原生会话结束、无回答及无其他控制指令等受限条件下尝试转给模型。第一条北京问题的自动语音测试和用户反馈成功，第二条完整长问题的自动测试已记录 DeepSeek 接手和语音合成；实际可靠性、不同家电指令及更多环境未完整验收。`s12-silent-fix/silent-finish.patch` 仅用于审阅最后一次本机源码差异，不能直接当成通用补丁部署。

`s12-device/handoff-candidate` 与 `persistent-candidate` 保存 S12 实验性源码，不含目标设备二进制与私有配置；脚本包含本机硬件、固件和摘要约束，不能通过更改或跳过校验用于其他机器。过程中的运行时、目标二进制、Mac 路径、设备地址和私钥必须重新核对。进程清理可审阅 `device/process_owner/README.md`；helper 丢失时新客户端会拒绝启动，既有发布器尚未自动安装 helper。

## Mac 看板和语音转写

`outputs/` 中为三套看板源码快照（S12A、S12、双设备入口）。代码与网页是本机实验版，不是项目发布包；旧设置写入逻辑依赖当时设备上的备份目录和脚本。**先审阅并核实设备身份、固件、对应备份和当前网络，禁止直接套用设置保存或覆盖设备配置。** 两机使用不同 SSH 别名与配置，切勿混用。

`s12-asr/asr_bridge.py` 是本机 Whisper 桥接源码的脱敏快照，需显式设置 `S12_SPEAKER_IP`；并要求重新配置 Mac 局域网地址、私密令牌、Whisper 程序和模型文件。原服务通过局域网 HTTP 传递短时音频，令牌用于访问控制但传输本身不加密；看板对话日志可能包含私人内容。网段、IP 变化、Mac 睡眠或未登录会影响追问；首轮能否独立运行应按设备实测。重装后需重新配置 LaunchAgent，而不能直接复用旧用户名路径。

双设备看板原本由 Mac 提供家庭局域网无密码访问（之前的用户选择），仅允许 Mac 本机填写 API Key；局域网内其他人可能访问看板。不要直接暴露公网。

## SSH 与密码

S12 曾开启公钥和密码认证。其原厂 PAM 模块曾把密码尝试写进系统日志；当时只为 SSH 单独配置了系统 `pam_unix`，并在未重启的状态下验证过密码及原有公钥登录。**重启后的认证及各系统槽位尚未复验**；不要直接启用原厂密码认证或上传日志。已备份原 `/etc/pam.d/sshd`、`/etc/shadow` 和 Dropbear 设置，路径在设备原本的受保护备份中，但是否仍存在须现场确认。

新 Mac 使用旧私钥前，应从可信备份恢复并设置合适权限，核验目标主机密钥；旧设备使用 `ssh-rsa` 时可能需要针对该设备单独配置兼容选项。绝不将私钥、密码、API Key、授权令牌或整份个人日志放到公开仓库。

## 重装前必须另存

GitHub 不是私密恢复材料的替代品。请将加密备份或用户控制的离线备份保存到**不会被重装抹掉的另一块介质**并验证能够读取：

1. 两台音箱各自的 SSH 私钥、公钥、已核验的主机密钥与专用连接配置；S12 的 SSH 密码及用户后来可能设置的新密码。
2. 原厂分区镜像、已验证的校验值、S12 个人数据及启动文件备份；这些可能包含设备密钥，严格保密。仅有镜像并不代表已验证可恢复 NAND/OOB/坏块。
3. 各音箱当前的 `/data/native_first.env` 等私密配置和 API Key；不能公开。现有本机 S12 备份日期早于最后几次更改，重装前设备在线时应单独备份当前版本。
4. Mac S12 Whisper 模型、桥接令牌、运行脚本和 LaunchAgent；模型也可以从可信来源重新下载并核对摘要。

备份完成后，先在另一设备验证能打开清单、读取密钥并解压，再重装。保留 TTL 作为网络和 SSH 失效时的恢复入口；任何刷写或挂载修改前先确认当前机型和启动槽位。
